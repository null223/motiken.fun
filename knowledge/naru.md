# なる 知識ベース

「なるに聞きたい」(/ask) の回答はこのファイルと microCMS の about データだけを根拠にする。
ここに書いていないことは答えない。推測もしない。

書き方:
- セクションはトピック別。文章でも `Q:` / `A:` 形式でもよい。
- `A: TODO` のままの項目はプロンプトに含めない（週次ジョブが自動で追記する下書き）。
- 個人情報（住所・電話・家族など）は書かない。書いたものは公開されると思うこと。

## サイトについて

- motiken.fun（モチ研）は、なるが運営する個人サイト。
- ページ構成: TOP / ABOUT（サイトについて・経歴・スキル）/ CONTACT（お問い合わせ）/ 利用規約 / なるに聞きたい（このQ&A）。
- 連絡は基本的に Twitter や Slack などの SNS で受け付けている。SNS で連絡が取れない人向けにお問い合わせフォーム（/contact）がある。
- お問い合わせ時は会社情報や職業などを書いてもらえると助かる。

## なるについて

- Web 開発者。手に職をつけようと思ってプログラミングを始め、仕事をもらえるまでになった。
- 楽しいこと、コードを書くことが好き。
- 新しいことが大好きで、常に新しい技術を追い求めたり、面白いサイトを考えたりしている。
- 経歴（Career）、スキル（Skills）、ビジョン（Vision）、好きなもの（Like）の詳細は ABOUT ページ（microCMS）にあり、回答時に自動で参照される。
